## Executive Summary

TruthGPU is a full-stack verification infrastructure that unifies LLM security and hallucination detection in a single accelerated GPU service. The system achieves breakthrough results:

- **11.4x NLI acceleration** with zero verdict change
- **4.57x end-to-end speedup**
- OOD adversarial robustness: **0.759 to 0.956** macro-F1
- Benign false positive rate: **5 percent to 2.5 percent**
- Hallucination recall: **67 to 89 percent** (zero false positives)

---

## Problem Statement

LLM deployments face two critical failure modes:

1. **Security**: Adversarial inputs (prompt injection, jailbreaks, obfuscation evasion) can subvert model behavior
2. **Hallucination**: Fluent but factually incorrect outputs, particularly numeric and relational errors

Both require neural-network verification layers, creating latency and cost bottlenecks. An additional challenge is **evaluation optimism**: safety classifiers trained on synthetic data reach 99 percent accuracy that collapses to 76 percent on genuine out-of-distribution obfuscated attacks.

A third requirement is **sovereignty**: many deployments (automotive, medical, defense, industrial) must verify offline, on-device.

---

## System Architecture

TruthGPU exposes a single GPU service with four shared RPCs (Embed, Nli, Classify, Similarity), so models load once:

- **AEGIS**: 8-class multilabel input-side security guardrail
- **HalluGuard**: NLI plus numeric output-side fact verification

![TruthGPU full-stack architecture: one cloud GPU service hosting AEGIS and HalluGuard, distilled onto a 4-SKU edge silicon family](/assets/images/truthgpu/fig1_architecture.png "Figure 1. TruthGPU full stack. One GPU service hosts both engines and shared acceleration; the same taxonomy and policy are distilled onto a 4-SKU edge silicon family, which escalates only gray-zone inputs to the cloud.")

Each input flows through a **layered pipeline**:
1. Deterministic rules and PII/DLP scanning on CPU (resolves clear cases immediately)
2. Ambiguous cases invoke the accelerated classifier
3. Decision policy emits (allow, escalate, block)

![Layered verification pipeline where cheap deterministic stages short-circuit clear cases and the parity gate guarantees verdict invariance](/assets/images/truthgpu/fig2_pipeline.png "Figure 2. Layered verification pipeline. Cheap deterministic stages short-circuit clear cases; the parity gate guarantees verdict invariance under acceleration.")

The same taxonomy and policy are distilled onto four edge silicon families (NXP, ST, Renesas, i.MX), escalating only gray-zone inputs to the cloud.

## Six Integrated Contributions

### A: Parity-Gated Acceleration

**Innovation**: Fused GPU kernels with automated verdict-label equivalence gate.

Core idea: Post-process logits (class permutation, normalization, threshold) within a single GPU kernel, eliminating host-device round-trips. Then enforce an automated **parity gate**:

- Zero top-one verdict mismatches between accelerated and reference implementations
- Confidence scores differ by at most epsilon between implementations

Deploy only if parity gate passes AND every quality-regression metric meets threshold.

**Result**: 1.8e-07 numerical error, zero top-one mismatch, zero confidence delta.

### B: Numeric cross-verification for Hallucination Detection

**Innovation**: Category-gated numeric layer running before NLI.

Extract numeric facts (value, unit, context) from both claim and evidence. Block cross-domain mismatches (interest rate vs. birth rate, even at same value) via category mapping and unit compatibility.

After unit normalization, flag contradiction if gap exceeds per-unit tolerance. The numeric layer runs **before** NLI: verdict is contradicted if any numeric contradiction found, else proceed to NLI.

Example: claim of "temperature is 25 degrees" is compatible with evidence of "25 Celsius" but incompatible with "25 Fahrenheit" depending on tolerance threshold.

**Result**: Recall improved 67 to 89 percent with zero false hallucination rate.

### C: Adversarial plus Targeted Hard-Negative Training

**Innovation**: Dual-gate loop raising robustness AND precision simultaneously.

1. **Baseline**: Train on in-distribution, evaluate OOD robustness (0.759 baseline)
2. **Adversarial augmentation**: Add LLM obfuscated attacks (whitespace, zero-width, script mixing, code obfuscation) - robustness jumps to 0.978 but false positives rise to 15 percent
3. **Targeted hard-negatives**: Identify benign examples incorrectly flagged unsafe, generate synthetic negatives to correct distribution
4. **Deploy iff**: Robustness meets minimum AND false-positive rate meets maximum

Post-hoc threshold tuning cannot improve OOD robustness (metric invariant to calibration), proving the **data-lever thesis**: this is a training data problem, not a threshold problem.

**Result**: OOD robustness 0.956, benign false-positive rate 2.5 percent.

### D: Multi-Signal Fusion

**Innovation**: Classifier union with deterministic rules, non-harm gate.

Combine ML classifier score with deterministic rules via logical union: flag unsafe if either classifier fires OR any rule matches.

Rules are designed so probability of matching on benign examples is near zero. A **non-harm gate** admits rules only if:
- Zero net increase in false positives on all benign slices (in-distribution, OOD, sensitive-but-legitimate)
- Fused recall meets or exceeds ML-only recall

**Result**: Adversarial macro-F1 improved 0.956 to 0.978 with zero added false positives.

### E: Safety-Constrained Selective Prediction

**Innovation**: Operating point under no-attack-leak constraint.

Route inputs into three categories:
- **Auto-allow** if confidence below low threshold
- **Auto-block** if confidence above high threshold
- **Review** if in middle band

Optimize thresholds to maximize coverage subject to:
- Auto-decision accuracy meets minimum target
- No attacks fall into auto-allow band

**Result**: Band [0.1, 0.9] achieves 100 percent auto-accuracy at 99.3 percent coverage with zero auto-allowed attacks.

### F: Cloud-to-Edge Unification

**Innovation**: Identical policy and taxonomy across heterogeneous compute.

- **Server-side**: mDeBERTa-v3 accelerated verifier (teacher)
- **Device-side**: INT8 char-CNN student, 0.113 MB, false negative rate zero on test
- **Shared**: Verdict label space, interface contract, decision policy
- **Propagation**: Gated OTA (regression gate before hot-swap)
- **Silicon**: NXP MCX N947, ST STM32N6, Renesas RA8M1, i.MX 93 gateway

Portable core (rules, DLP, preprocessing, decision) is silicon-independent; per-chip HAL backends implement NPU inference and secure boot.

- **Hardware**: NVIDIA H200 (143 GB), CUDA 13

## Limitations and Open Items

We are explicit about what is **not** yet established:

1. **External generalization**: Detection metrics use internal synthetic and zero-overlap held-out data. Real-customer traffic is unvalidated.
2. **Edge silicon latency**: On-device latency/power are design estimates; measurement awaits board bring-up and NPU compilation.
3. **Mid-size edge encoders**: 5-80 MB models are a design option, not yet trained.
4. **Selective prediction universality**: 100 percent accuracy achieved on small, well-separated set.

We report these as open items; the system gates exist precisely to prevent optimism from shipping.

---

## Key Takeaways

1. **Acceleration need not trade off safety**: Parity gates guarantee verdict preservation in hardware kernels.
2. **Robustness and precision are not antithetical**: A data-centric loop resolves the tradeoff.
3. **Numeric fact checking complements NLI**: Category-gated unit cross-verification catches contradictions NLI misses.
4. **Edge deployment is feasible**: Distilled INT8 models fit the under-0.8-MB ceiling with zero false negatives.
5. **Measurement transparency matters**: Speed, cost, verdict-preservation are measured; external generalization and on-silicon latency are next milestones.

---

## Conclusion

TruthGPU unifies LLM security and hallucination verification in one accelerated GPU service that provably preserves the safety verdict, attains robustness and precision together through a data-centric loop rather than post-hoc tuning, and extends the same policy to data-sovereign edge silicon. Speed, cost, and verdict-preservation are measured; external detection-quality generalization and on-silicon latency are the next milestones.
